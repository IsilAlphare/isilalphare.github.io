- 支持原生 dialog 焦点范围、Escape 关闭、焦点返回和减少动态效果。
- 验证：构建通过；桌面与 390px 手机端操作完成；刷新恢复、重置及无后端验证通过。正式接入前需替换本地存储逻辑并移除演示入口限制。


## 侧边陪伴细化（2026-09-22）
- 星星使用首页同源的立体四芒星几何，去掉轨道；未点亮半透明，点亮后实心。
- 固定于视口，支持鼠标/触屏拖动、边界限制、松手轻晃；拖动超过 6px 不触发点亮。
- 无边框反馈与“留个言吧”；3.5 秒后提示退出，“星光已留下”淡出，再点星星仍能留言。
- 信纸双线边缘与信封装饰；四种印记分别为星芒闪耀、月牙摇曳、叶片翻转、海风波动。
- 减少动态效果设置会停用新增动画；标签页隐藏时暂停立体动画。
- 本次验证：61 页生产构建通过；浏览器验证拖动不点亮、点亮提示消失、弹窗及 390px 布局，控制台无错误。仍仅本地开发预览。


## 全站入口与留言展示（2026-09-22）
- 开发预览中由 BaseLayout 唯一挂载小星星，所有使用基础布局的页面常驻，首页不再重复挂载。
- /guestbook/ 展示“星间来信”，页脚和星星写信面板提供入口。生产模式仅有准备中提示，不包含示例信件。
- 文章详情（包括手写页面）和游记详情挂载 LetterBoard；目录页不挂载。
- 点亮后文章/游记入口分别为“给这篇文章留言”“给这段旅途留言”，滚动到底部并聚焦输入框；减少动态设置下直接定位。
- “已有 128 颗流星划过天幕”为明确标记的示例统计，未使用真实计数。
- 本地信笺按页面路径隔离，key 为 starry-dome:letters-preview:v1:<scope>；guestbook 兼容星星原型中保存的一封来信。所有用户文本使用 textContent 展示。
- 本轮验证：62 页构建、diff 检查通过；文章保存刷新恢复、游记隔离和输入框焦点、390px 留言簿无横向溢出、控制台无错误。
