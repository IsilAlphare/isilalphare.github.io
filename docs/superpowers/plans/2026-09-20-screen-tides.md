# 银幕潮汐第一版

用户已确认：全文收录三篇影评，采用作品条目与独立文章页，不设置豆瓣外跳。

**Goal:** 收藏馆 → 银幕潮汐 → 完整影评，提供返回栏目入口。
**Architecture:** 复用 posts collection，以可选 screen 字段保存作品、类型和原文摘句；栏目与收藏馆从同一 collection 读取，避免维护两份作品清单。
**Tech Stack:** Astro 静态生成、Markdown、现有 CSS。

## 约束
- 保留原标题、日期、正文措辞，只整理段落；重复的后翼弃兵只收录一篇。
- sourceDoc 保存原始来源，仅用于源码核对，页面不展示外部链接。
- 归入拾光摘录；增加剧透提示和返回栏目链接。
- 图片暂缓；其他收藏类别不改动；不提交、不推送、不删除文件。
