# 星夜手札与文章页 Implementation Plan

**Goal:** 按用户确认方案统一文章美学，逐星记改为带抽象地景和单船阅读位置的记忆航道。
**Architecture:** 保留数据和正文。文章复用 FlowingLabel / CelestialMotif；新增 SVG 地景组件、页面专用样式以及独立纯函数阅读进度模块。静态内容默认可读，滚动用 rAF 更新，ResizeObserver 重算尺寸，减少动态偏好关闭呼吸动画。
**Scope:** 本地实现和验证；不接评论、不提交或推送、不替换已有照片。

- [x] 文章目录统一首页标题、副标题及分类图案，细化链接卡片；验证分类锚点及移动布局。
- [x] 绘制五种细线地景，更新星穹入口、卡片与结尾；保留全部节点文字、照片及文章链接。
- [x] 单船连续阅读位置与主题切换：先验证纯函数边界，后接滚动与尺寸监听；验证前后滚动和窄屏。
- [x] Node 检查、生产构建、浏览器桌面与手机检查；无 JS / reduced-motion 保证内容可读。

验证：Node 2 项通过；生产构建 61 页；桌面与 390px 视口检查通过，文章和航道无横向溢出。浏览器确认向下移动、向上返回和主题变色，无脚本错误。静态 HTML 保留所有节点正文，减少动态样式关闭呼吸与过渡。
